# 路线图与待办

> 只保留尚未完成或未验证的事项。历史路线图、已完成批次和旧设计记录见 Git 历史；逐版本变化见 [CHANGELOG.md](../CHANGELOG.md)。当前能力与验收边界见 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)。

## 发布与分发

- 插件市场提交、上架与首次安装体验；只在用户明确要求时执行。
- 发布流程的一键化：`dev`→`main`、打标签、双远端推送目前仍分步执行。

## 数据与报告口径

- 0 分是否计入均分：需要确认是否增加开关，或在报告中明确口径。
- 参与者覆盖不足提示：可在概览补充“评分覆盖不足 1/3”的参与者提示。
- 报告浅色主题专门设计：当前是深色 token 反相，封面和图表配色未单独取值。
- 报告 320/390px 复验：图册/列表切换在窄屏下的可发现性。

## 工作区与运维

- 面板断连时保留页面框架：当前整块替换为“连接失败 + 重试”。
- 历史场次数据库增长：考虑按保留期清理历史场次，与报告保留期解耦。
- `auto_cleanup_reports` 默认关闭，长期运行可能堆积报告；可考虑首次生成报告时提示。

## 未验收边界

- 0.13.18 真实 QQ/NapCat：`send_group_msg`、`get_msg`、`real_seq`、`/vote send` 以及限流延迟场次。
- 单文件报告 `file://` 双击、真实头像下载、跨进程重启 E2E、500 MB 真实照片、多群并行、AstrBot 4.4.x。
- 报告重新导出是静态快照，不会回溯更新旧 HTML。

## 明确不做

- 旧报告、旧配置和旧数据的批量兼容与重导；需要时重新导出。
- 插件市场注册/上架不随版本收尾自动执行。
